# AI Business OS

AI-powered Lead Management & Business Automation System built with n8n, Supabase, Gmail, Telegram, and AI Agents.

## Features

- Lead Capture Form
- AI Lead Analysis
- Supabase Database Integration
- Telegram Notifications
- Automated Gmail Responses
- AI-Powered Lead Categorization
- Business Intelligence Dashboard
- End-to-End Workflow Automation

## Workflow

1. User submits lead form
2. Data stored in Supabase
3. AI Agent analyzes inquiry
4. Lead category and priority generated
5. Telegram notification sent
6. Automatic email response sent
7. Lead stored for future follow-up

## Tech Stack

- n8n
- Supabase
- OpenRouter AI
- Gmail API
- Telegram Bot API
- Lovable
